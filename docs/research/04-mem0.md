# Mem0 source review

## Confirmed implementation

`mem0/memory/main.py` defines `Memory`, with synchronous and asynchronous paths. `Memory.add` parses messages, extracts facts when `infer` is enabled, calls `_add_to_vector_store`, writes history through `SQLiteManager`, and performs entity linking. `Memory.search` calls `_search_vector_store`; `update`, `delete`, `delete_all`, and `history` are public operations. `mem0/memory/storage.py` is the local history store. Vector backends are selected by `mem0/utils/factory.py` and implemented under `mem0/vector_stores/`.

`mem0/configs/prompts.py` confirms model-based fact extraction and an update prompt with four operations: ADD, UPDATE, DELETE, and no change. The procedural prompt targets a complete agent execution summary. This is useful for coding memory but the default fact prompt is personal-assistant oriented. The code stores old/new values in history, but the visible public model is still vector-first; source evidence references and formal valid-time intervals are not the central canonical object.

Search supports metadata filters, thresholds, optional reranking/explanation paths, and temporal-related notices. The repository has extensive vector-store tests and evaluation material, but benchmark comparability depends on configuration and external providers.

## Engineering assessment

Strong decisions: simple API; broad provider factories; explicit history; clear update operation prompt; sync/async parity; local SQLite option; filterable user/agent/run scope.

Weaknesses: model-directed reconciliation can delete or overwrite without an evidence ledger; vector similarity is a weak duplicate/contradiction oracle; personal facts are not coding-task evidence; provider breadth increases test and deployment cost.

## Reuse and rejection

Reuse the small add/search/update/history API, provider interfaces, and explicit operation classification as a candidate—not authority. TermyteDB will require evidence validation and append-only versions before reconciliation. License is Apache-2.0 (`LICENSE`); preserve license and notices for reused code.
